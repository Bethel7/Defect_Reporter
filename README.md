Defect Reporter App

The Defect Reporter App is a mobile application built with Flutter that enables employees to quickly report and track defects within the organization. The app allows users to submit defect reports with details such as description, location, images, and severity level. It also integrates with a backend API for real-time data synchronization, push notifications, and offline support.

✨ Key Features

Submit defect reports with title, description, location, and images.

Offline mode with cached submissions that sync once online.

AI-powered classification (severity and department tagging).

Real-time push notifications and report status tracking.

Secure authentication and role-based access.

🛠 Tech Stack

Frontend: Flutter (Dart)

Backend: .NET Core API with SQL Server

Database: SQL Server

Cloud/Services: Firebase (FCM), Azure OpenAI (AI classification – optional)
